Provenance of the files in this directory
=========================================

These are the raw artefacts behind every number in the report. They are
included so that its tables can be checked without rerunning anything.

stage_a.csv            6 feature rows, fixed linear SVM, 5 place-holdout folds
stage_a_nb.csv         the same folds under the supplementary naive Bayes pass,
                       which produced the C6 columns of the report's Section 3.4
stage_b.csv            10 feature/classifier rows, same folds; also carries the
                       per-fold columns ba_0 .. ba_4
selection.json         the feature and classifier that were locked
val_metrics.json       validation confusion matrix and per-class metrics
test_metrics.json      test confusion matrix and per-class metrics
test_predictions.csv   one row per test image: filename, group_id, y_true, y_pred
dataset_summary.md     the per-class, per-split counts

All of them come from one run on 2026-10-27, on the 534-image split that the
location repair described in Section 2.7 of the report produced. The three
pipeline commands and the supplementary naive Bayes pass were run in that
order against this source tree:

  python -m src.task3.run_stage_a
  python -m src.tools.run_stage_a_nb
  python -m src.task3.run_stage_b
  python -m src.task3.evaluate

run_stamp.json therefore records the fingerprint of the code under src/task3/
and of data/annotations/splits.csv exactly as they are shipped here. A plain

  python -m src.task3.run_stage_a
  python -m src.task3.run_stage_b

reuses the tables above instead of asking for --force.

The guard is deliberate: it fires when splits.csv or src/task3 is edited after
the stamp was written, so a table produced by other code is never quoted as a
fresh result.

The test set was scored once, after the selection was locked. Section 3.6 of
the report states the limitation that goes with that sentence.

Figure files live in docs/figures/. The scripts that drew them are tools of the
working repository and are not part of this archive; nothing in the classifier
depends on them.
