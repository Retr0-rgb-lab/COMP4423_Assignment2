# Annotation glossary

The annotation record was written in Chinese and has been translated to English.
This table is the whole mapping, so any cell of any CSV can be traced back to the
wording it came from. Nothing else in a row was touched: the file name, the class,
the group id and the split are as they were recorded.

The place names follow the wording of the report, and the scene classes are the
thirteen English types printed in Section 2.1, so the counts in the report can be
read against the CSVs without a second translation.
